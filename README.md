# audio.lgbt

Групповые аудио- и видеозвонки со сквозным шифрованием, браузерным клиентом и нативным приложением Windows. Сервер, сайт и приложение находятся в этом репозитории.

- Микрофон, камера, демонстрация экрана со звуком, чат и список участников.
- Настройки устройств и громкости во время звонка; отдельная громкость участника до 200%.
- Приглашение по ссылке и локальная история комнат.
- Свой сервер через Docker, автоматический HTTPS и встроенный TURN-over-TLS.
- Необязательные локальные аккаунты: создавать комнаты могут авторизованные пользователи, гости входят по ссылке без регистрации.
- Windows-клиент без WebView: WinForms/.NET, Go/Pion, нативный захват экрана и WASAPI.

[Открыть audio.lgbt](https://audio.lgbt) · [Скачать приложение](https://audio.lgbt/download) · [Развернуть свой сервер](docs/SELF-HOSTING.md)

## Самостоятельное размещение

На Linux с Docker Compose:

```sh
git clone https://github.com/aes-gcm/audio.lgbt.git
cd audio.lgbt
cp .env.example .env
# Укажите свой домен и публичный IP в .env.
mkdir -p data && chmod 700 data
docker compose pull
docker compose up -d
```

Нужны свободные TCP 443 и UDP 3478. Не ставьте обычный HTTP-прокси перед 443: этот порт используется также для TURN-TLS. Подробные инструкции, аккаунты и резервные копии — в [руководстве](docs/SELF-HOSTING.md).

## Разработка

Go 1.26; фронтенд — обычные HTML/CSS/JS без сборщика.

```sh
go test ./...
go run ./cmd/zvonok -dev -http 127.0.0.1:8080
```

Браузерные тесты: `npm ci`, затем `npx playwright install chrome`. Тесты используют Chrome; конкретные сценарии находятся в `test/e2e`. [Сборка Windows](desktop/README.md) требует Windows 10/11 x64, .NET 10 SDK и Visual Studio C++ Build Tools.

## Шифрование и границы доверия

Ключ комнаты находится во фрагменте приглашения после `#`. Клиенты шифруют аудио, видео и чат до отправки SFU; сервер видит метаданные соединений. Обладатель приглашения может подключиться, поэтому не публикуйте ссылку на закрытый звонок. HTTPS обязателен для реального развёртывания.

Браузер получает код от владельца сервера: злонамеренно изменённый клиент способен раскрыть ключ. Проверяйте, какому серверу доверяете. Самописная обработка звука и клиент Windows продолжают развиваться; опубликованные версии отмечены preview, установщик пока без подписи издателя. Заявлений о независимом аудите безопасности нет.

## Структура

`cmd/zvonok` — сервер и управление аккаунтами; `internal` — SFU, транспорт, шифрование и нативный движок; `web` — сайт; `desktop/AudioLgbt.Native` — Windows-клиент; `desktop/AudioLgbt.Capture` — нативный захват; `scripts` — сборка; `test` — проверки; `third_party` — необходимые исправления Pion.
